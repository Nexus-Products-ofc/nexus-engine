# Build NexusEngine.exe (Windows)

A real `.exe` must be built **on Windows**.

## Steps
1. Install Python 3.9+ (check Add to PATH)
2. Double-click `build_exe.bat`
3. Output: `dist\\NexusEngine.exe`

Or:
```bat
python build_exe.py
```

Upload the EXE to GitHub Releases for the website download button.

SmartScreen warnings are normal until you buy a code-signing certificate.
