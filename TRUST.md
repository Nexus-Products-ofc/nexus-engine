# Why Nexus Engine is legitimate (not a scam)

## What we are
- Open-source **Python** game engine (MIT license)
- Source code is public on GitHub — anyone can read every line
- No installer that phones home for “activation”
- No request for money, seed phrases, or bank data to “download”

## Trust signals
1. **Public source** — `nexus_engine/` on GitHub
2. **MIT LICENSE** — commercial use allowed, terms clear
3. **Releases page** — versioned downloads only from GitHub
4. **Checksums** — SHA-256 for release files (when published)
5. **Issues / Discussions** — public bug reports and forum
6. **Security policy** — SECURITY.md

## About Windows warnings
A green “Verified publisher” badge requires a **paid Authenticode certificate** (identity verification + yearly cost). Many professional open-source tools ship unsigned until they fund that. Professional means transparent source + official channels.
