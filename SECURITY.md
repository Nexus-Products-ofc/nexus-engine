# Security Policy

## Official sources only

Nexus Engine is distributed **only** from:

- GitHub repository: https://github.com/heitorhanzelgontijo-svg/nexus-engine
- GitHub Releases: https://github.com/heitorhanzelgontijo-svg/nexus-engine/releases
- GitHub Pages: https://heitorhanzelgontijo-svg.github.io/nexus-engine/

We never ask for passwords, crypto payments, or remote access to “activate” the engine.

## Windows SmartScreen

Unsigned open-source software may show **“Windows protected your PC”**.
That is Microsoft’s default warning for publishers without a paid code-signing certificate.
It is **not** proof of malware. Prefer ZIP + Python launchers from this repository.

## Reporting vulnerabilities

Open a private security advisory or an issue labeled `security` on the GitHub repository.
Do not post exploits publicly until a fix is available.
