3. Build MSI yourself

On a Windows PC after extract:

python build_msi.py
Why no direct MSI file on the homepage? A real Microsoft Installer (.msi) must be built on Windows (WiX / msilib) and ideally code-signed. Without a paid certificate, SmartScreen still warns. We ship Python + .bat launchers (transparent, open source) and optional MSI via Releases.

Windows Defender / SmartScreen

Windows protects your PC from unknown publishers. Open-source tools without a paid code-signing certificate often trigger this. It does not mean the project is malware.

  1. Prefer running Nexus Engine.bat (Python scripts), not random .exe from the internet.
  2. If SmartScreen appears: More info → Run anyway.
  3. Or right-click the ZIP/file → Properties → check Unblock → Apply.
  4. Only download from the official GitHub: heitorhanzelgontijo-svg/nexus-engine.

Learn — two paths

A) Unity-like editor (visual)

Double-click Nexus Engine.bat → Hierarchy, Scene, Inspector, Console, Play.

  • N — new object
  • Del — delete
  • Space — play/pause
  • F1 — FPS overlay

B) Code path (more optimized)

Write Python for full control and performance tuning.

from nexus_engine import (
  Application, World, Transform,
  SpriteRenderer, Camera, Turbo, Debug
)
Turbo.set("turbo")  # or ultra
world = World("Game")
# add entities + components...
Application(
  title="My Game",
  backend="pygame",
  turbo="turbo",
).run(world)
