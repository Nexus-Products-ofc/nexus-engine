3. Exemplo mínimo

from nexus_engine import Application, World, Transform, SpriteRenderer, Camera, Debug

world = World("Game")
cam = world.create_entity("Cam")
cam.add_component(Transform(0, 0))
cam.add_component(Camera())
p = world.create_entity("Player")
p.add_component(Transform(100, 100))
p.add_component(SpriteRenderer(color=(100, 200, 255), width=32, height=32))
Debug.log("ok")
Application(title="Meu Jogo", backend="pygame").run(world)

6. Como construímos a Nexus

  1. Núcleo — NexusEngine, Application, Time, EventBus
  2. ECS — World, Entity, Component, System
  3. Gameplay — Physics2D, Particles, Tilemap, UI, Audio
  4. Unity-like — Prefabs, Pool, Coroutines, SceneManager, Resources
  5. Multi-backend — Pygame, Ursina, Panda3D, Taichi
  6. DX — Splash Made in Nexus, Debug, Gizmos, Engine Mode
  7. Build + site — PyInstaller multi-OS, GitHub Pages, READMEs i18n
