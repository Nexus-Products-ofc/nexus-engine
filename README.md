## Quick start

```bash
git clone https://github.com/heitorhanzelgontijo-svg/nexus-engine.git
cd nexus-engine
pip install pygame numpy
python main.py
```

On open you will see the **Made in Nexus** splash screen.

### Build your game

```bash
python build.py
python build.py windows --name MeuJogo
python build.py linux
python build.py html
```

## Features

- ECS (Entity / Component / System / World)
- Physics2D, Particles, Tilemap, UI Canvas
- Prefabs, ObjectPool, Coroutines
- Scene save/load (JSON)
- Backends: Pygame, Ursina, Panda3D, Taichi
- Multi-language website under `docs/website/`

## Controls (showcase)

A/D move · Space jump · Shift dash · Click explode · F5/F9 save/load · ESC quit
