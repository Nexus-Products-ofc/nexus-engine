Nexus Engine is built so you can focus on the game itself. The visual editor handles scenes, entities, and properties, while the ECS keeps your game logic organized as entities, components, and systems. Projects are saved as readable JSON files with the `.nexusEng` extension, so they are easy to inspect, version, and edit by hand.

Everything you need to start is included: Turbo performance profiles, audio, visual effects, and particles. The engine is released under the MIT license.

## Features

- **Engine Mode**: visual editor with Hierarchy, Scene, Inspector, Console, and Project panels
- **ECS**: entities, components, and systems
- **2D and 3D**: backends for both kinds of games
- **Turbo profiles**: performance presets for different needs
- **Audio, VFX, and particles**: built in
- **`.nexusEng` projects**: scenes and entities saved as JSON
