# Nexus Engine Examples

| Example | Command | Needs |
|---------|---------|-------|
| 2D Platformer | `python main.py --platformer` | pygame |
| 3D First Person | `python main.py --fps` | ursina (fallback mock) |
| 3D Third Person | `python main.py --tps` | ursina (fallback mock) |
| Engine Mode (Unity-like) | `python main.py --editor` | pygame |
| Showcase | `python main.py` | pygame |

```bash
pip install pygame numpy
pip install ursina   # optional, for real 3D
```
