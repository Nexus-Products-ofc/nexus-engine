# Code of Conduct

## Our pledge

We pledge to make participation in Nexus Engine a harassment-free experience for everyone.

## Standards

**Positive:** empathy, respectful feedback, collaboration, responsibility.

**Unacceptable:** harassment, insults, trolling, personal or political attacks, publishing private information, sexualized language or imagery in project spaces.

## Enforcement

Report issues to the repository maintainers via GitHub. Maintainers may warn, remove content, or ban contributors who violate this code.

## Scope

This Code applies in project spaces and when representing the project publicly.
