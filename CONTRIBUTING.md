# Contributing to Nexus Engine

Thank you for helping make Nexus better. All skill levels are welcome.

## Ways to contribute

1. **Code** — fix bugs, add systems, improve backends
2. **Examples** — small complete games and tutorials
3. **Translations** — improve `docs/website/locales.json`
4. **Docs** — clarify APIs
5. **Issues** — report bugs with OS, Python version, and steps

## Setup

```bash
git clone https://github.com/heitorhanzelgontijo-svg/nexus-engine.git
cd nexus-engine
pip install -r requirements.txt
python main.py
```

## Pull requests

1. Fork the repo
2. Branch: `git checkout -b feature/my-change`
3. Test with `python main.py`
4. Open a PR

## Releases

Tag format: `v0.3.0` — publish GitHub Releases with changelog and zip asset.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
